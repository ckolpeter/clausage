# Security Policy

Clausage stores your claude.ai session only in the local Electron profile on your machine and sends it nowhere except `claude.ai` (or, in Claude Code mode, your local OAuth token to `api.anthropic.com`).

If you find a security issue (e.g. credentials leaking to logs, other hosts, or other apps), **please do not open a public issue**. Use GitHub's private vulnerability reporting: *Security → Report a vulnerability* on this repository.

如果發現資安問題（例如憑證外洩），請勿公開開 issue，改用本儲存庫的 *Security → Report a vulnerability* 私下回報。
